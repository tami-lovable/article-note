# 기사 프로젝트 노트

기사 작성 프로젝트를 정리하는 한 페이지짜리 노트입니다. HTML 파일 하나로 되어 있어서 설치 없이 바로 열 수 있습니다.

## 주요 기능

- **프로젝트 한 줄**: 프로젝트를 한 줄로 적는 칸
- **주제**: 대주제 표시 (현재: 경제)
- **할 일 체크리스트**: 5개 항목, 체크 표시 가능
- **날짜별 기록**: 11/18부터 하루 한 줄 기록, 버튼으로 다음 날짜 추가
- 휴대폰 화면에서도 읽기 편한 반응형(화면 크기에 맞게 바뀌는) 디자인
- 입력한 내용은 사용하는 브라우저에 자동 저장 (다른 기기와는 공유되지 않음)
- 전화번호·주소 같은 개인정보 입력 칸 없음

## 사용 방법

1. 이 저장소를 내려받습니다(Download ZIP 또는 `git clone`).
2. `project-note.html` 파일을 더블클릭해서 브라우저(인터넷 열람 프로그램)로 엽니다.
3. 칸에 내용을 적습니다. 따로 저장 버튼은 없습니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `project-note.html` | 노트 페이지 본체 |
| `README.md` | 이 설명서 |

## 참고

- 브라우저의 저장 기능(localStorage, 브라우저 안에 작은 데이터를 보관하는 기능)을 사용합니다. 브라우저 기록을 지우면 입력한 내용도 함께 지워질 수 있습니다.
